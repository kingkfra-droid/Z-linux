# Z-linux

A Debian-based Linux distribution with custom build tools and configuration.

## Overview

Z-linux is a customized Linux operating system based on Debian, designed with modular components for building, bootstrapping, and configuring the OS.

## Directory Structure

- **`bootstrap/`** - Bootstrap scripts and components for initial OS setup
- **`build/`** - Build scripts and compilation tools
- **`config/`** - Configuration files for the OS
- **`scripts/`** - Utility scripts and automation tools
